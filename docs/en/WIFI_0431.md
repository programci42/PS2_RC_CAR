# 0.4.31 — shared language selection and relay control recovery

The owner reported a latched movement, smoke from the relay board and intermittent USB command failures. Live settings also showed a concrete configuration mismatch: the left motor group had been changed to R7/R8, but all four face-button programs still referenced R5/R6. TRIANGLE requested R4/R6. The settings were corrected to use R7/R8, and future group changes remap existing gamepad relay actions as well as web movements.

Smoke is evidence of a hardware fault, not proof of a particular software cause. This release cannot detect welded contacts, validate motor wiring/current ratings or repair damaged relays.

## Changes

- Turkish is the default for TV and web UI; Settings selects Turkish / English. The shared choice persists in `dil.json` beside the ELF. TV text uses ASCII Turkish for the existing debug font. Protocol values, filenames and user source code remain unchanged.
- Startup never sends a readiness ON pulse.
- Failed USB OFF commands retain the last acknowledged mask instead of falsely clearing it. The panel distinguishes uncertain outputs, output reset, USB/configuration failure and device absence.
- An IOP fault latch stops independently of EE status polling. A possibly delivered ON is recorded conservatively before the USB operation; new ON commands are blocked during a fault, and opposite relay pairs are checked in the IOP as well as the EE.
- Rebind can recover a faulted transport while preserving conservative output state. Late DMA callbacks remain generation-checked. Fresh movement after an error requires released controls and completed OFF reset.
- Repeated command failures no longer append the same error at every reset attempt. `/relay/diagnostics` and expanded `/status` expose USB result and uncertainty/reset state.

The earlier log contained repeated relay USB transfer failures. This observed test sequence did not reproduce loss of readiness. A brief test with motor power removed does not establish that motor-load electrical disturbances or damaged contacts are resolved. The log was preserved for further diagnosis.
