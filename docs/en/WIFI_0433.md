# 0.4.33 — individual relay test tab

The web panel adds a localized Relay Test tab (Turkish default: Röle Test), R1–R8 toggles and All OFF. Green reflects the last acknowledged USB output command, not measured contact continuity. Pending requests do not turn buttons green; unavailable/uncertain state is shown in amber.

Manual masks use the existing asynchronous relay scheduler, including break-before-make and interlocks for R1/R2, R3/R4, R5/R6 and R7/R8. Gamepad input cancels manual testing. Web requests renew a one-second lease; tab exit, page hiding and loss of focus request OFF. A USB transport failure can prevent that OFF command reaching the board, so the previous unconditional browser claim of stopping within one second has been removed.

Tests: all 255 nonzero masks checked against the interlock, stale commands, lease renewal/expiry, network loss, gamepad takeover, fault rejection, actual EE scheduler with mocked relay RPC, page handlers, HTTP JavaScript route/MIME, protocol suite and native EE/IOP regression harness. No live relay actuation was performed: motor power was connected, and the owner reported damaged contacts.

Release: 809,352 bytes. Deployment and running-image activation are separate; the new ELF must be opened after installation.

Deployment: uploaded to mc0:/Wifi/WIFI.ELF and verified using HEAD byte count only (809,352). No retained card backup, installed-file download, remote restart or live relay actuation. The final image has not been activated during this task.
